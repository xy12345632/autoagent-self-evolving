# AutoAgent 配置指南

## 配置文件结构

```
autoagent/config/
├── config.yaml        # 主配置文件
├── config_manager.py  # 配置管理器
└── secrets_manager.py # 密钥管理器
```

## 配置管理API

### ConfigManager

```python
from autoagent.config.config_manager import ConfigManager

config = ConfigManager()

# 按路径获取
value = config.get("model_providers", "opencode_zen", "default_model")

# 获取带默认值
value = config.get("tools", "web_search", "provider", default="duckduckgo")

# 获取全部配置
all_config = config.get_all()

# 检查配置是否存在
has_key = config.has("memory", "type")

# 获取API密钥
api_key = config.get_api_key("opencode_zen")
```

### 配置验证

```python
# 自动验证配置
config.validate()

# 验证特定部分
config.validate_section("model_providers")
```

## 环境变量覆盖

配置支持使用环境变量覆盖：

```bash
export AUTOCODER_API_KEY="your-key"
export OPENROUTER_API_KEY="your-key"
```

在配置文件中引用：

```yaml
opencode_zen_api_key: ${AUTOCODER_API_KEY}
openrouter_api_key: ${OPENROUTER_API_KEY}
```

## 敏感信息管理

### 使用SecretsManager

```python
from autoagent.config.secrets_manager import SecretsManager

secrets = SecretsManager()

# 存储密钥
secrets.set("api_key", "sk-xxx")

# 获取密钥
api_key = secrets.get("api_key")

# 删除密钥
secrets.delete("api_key")

# 列出所有密钥名（不暴露值）
keys = secrets.list_keys()
```

## 故障排除

### 配置不生效

1. 检查配置文件路径
2. 确认YAML格式正确
3. 验证环境变量是否设置
4. 查看日志中的配置加载信息

### 密钥获取失败

1. 确认密钥管理器已初始化
2. 检查密钥文件权限
3. 验证API密钥有效性

### 配置验证错误

```python
# 启用调试模式
config.debug = True

# 手动验证
config.validate()
```
