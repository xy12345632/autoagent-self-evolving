# AutoAgent 工具系统

## 概述

AutoAgent 内置40+工具，涵盖网页搜索、文件操作、代码执行、AI能力等多个领域。所有工具通过统一的 `ToolRegistry` 进行注册和管理。

## 工具分类

```
tools/
├── base_tool.py          # 工具基类
├── tool_registry.py      # 工具注册表
├── tool_executor.py      # 工具执行器
├── tool_learner.py       # 工具学习
├── tools_loader.py       # 工具加载器
├── web_tools/           # 网页工具
│   ├── search.py        # 网页搜索
│   ├── browse.py        # 网页浏览
│   ├── extract.py       # 内容提取
│   └── vision.py        # 视觉分析
├── system_tools/        # 系统工具
│   ├── terminal.py      # 终端命令
│   ├── file_ops.py      # 文件操作
│   └── code_execute.py  # 代码执行
├── ai_tools/            # AI工具
│   ├── image_gen.py     # 图像生成
│   ├── tts.py           # 文本转语音
│   ├── transcription.py # 语音转文字
│   └── vision_analysis.py # 图像分析
├── planning_tools/      # 规划工具
│   ├── planner.py       # 任务规划
│   ├── cron_job.py      # 定时任务
│   └── memory_mgmt.py   # 记忆管理
└── delegation_tools/    # 委托工具
    ├── subagent.py      # 子代理
    └── rpc_call.py      # RPC调用
```

## 工具详解

### 1. 网页工具 (web_tools)

#### web_search - 网页搜索

```python
# 功能: 使用DuckDuckGo搜索网页
# 参数:
#   - query: str, 搜索关键词
#   - num_results: int, 返回结果数量(默认5)

result = await tool.execute(
    query="Python asyncio tutorial",
    num_results=10
)
```

**返回格式**:

```json
{
    "success": true,
    "results": [
        {
            "title": "Python asyncio文档",
            "url": "https://docs.python.org/asyncio",
            "snippet": "asyncio是Python的异步编程库..."
        }
    ]
}
```

#### browse - 网页浏览

```python
# 功能: 访问并获取网页内容
# 参数:
#   - url: str, 网页URL
#   - method: str, 请求方法(GET/POST)

result = await tool.execute(
    url="https://python.org",
    method="GET"
)
```

#### extract - 内容提取

```python
# 功能: 从网页中提取特定内容
# 参数:
#   - url: str, 网页URL
#   - selector: str, CSS选择器或XPath
#   - pattern: str, 正则表达式模式

result = await tool.execute(
    url="https://news.python.org",
    selector="article.headline"
)
```

#### vision - 视觉分析

```python
# 功能: 分析图片内容
# 参数:
#   - image_url: str, 图片URL
#   - prompt: str, 分析提示

result = await tool.execute(
    image_url="https://example.com/chart.png",
    prompt="描述这个图表的主要内容"
)
```

### 2. 系统工具 (system_tools)

#### terminal - 终端命令

```python
# 功能: 在系统终端执行命令
# 参数:
#   - command: str, 要执行的命令
#   - cwd: str, 工作目录

result = await tool.execute(
    command="git status",
    cwd="/path/to/project"
)
```

**安全限制**: 仅允许配置的白名单命令。

**白名单默认配置**:

```yaml
tools:
  terminal:
    allowed_commands:
      - ls
      - cd
      - pwd
      - git
      - npm
      - node
      - python
```

#### file_ops - 文件操作

```python
# 功能: 读写文件
# 操作: read, write, append, delete, list

# 读取文件
result = await tool.execute(
    operation="read",
    path="/path/to/file.txt"
)

# 写入文件
result = await tool.execute(
    operation="write",
    path="/path/to/file.txt",
    content="文件内容"
)
```

#### code_execute - 代码执行

```python
# 功能: 在沙箱中执行代码
# 参数:
#   - code: str, 要执行的代码
#   - language: str, 编程语言
#   - timeout: int, 超时时间(秒)

result = await tool.execute(
    code="print('Hello, World!')",
    language="python",
    timeout=30
)
```

**执行环境**: Docker容器隔离

### 4. 规划工具 (planning_tools)

#### planner - 任务规划

```python
# 功能: 将复杂任务分解为步骤
# 参数:
#   - task: str, 任务描述
#   - constraints: dict, 约束条件

result = await tool.execute(
    task="创建一个小红书账号",
    constraints={
        "time_limit": "1周",
        "resources": ["手机", "邮箱"]
    }
)
```

**返回格式**:

```json
{
    "steps": [
        {"id": 1, "action": "准备手机号", "duration": "5分钟"},
        {"id": 2, "action": "下载APP", "duration": "3分钟"},
        {"id": 3, "action": "注册账号", "duration": "10分钟"}
    ]
}
```

#### cron_job - 定时任务

```python
# 功能: 创建和管理定时任务
# 操作: create, list, delete, pause, resume

result = await tool.execute(
    operation="create",
    job_id="daily_report",
    cron="0 9 * * *",
    action="send_daily_report"
)
```

#### memory_mgmt - 记忆管理

```python
# 功能: 管理持久记忆
# 操作: add, search, update, delete

# 添加记忆
result = await tool.execute(
    operation="add",
    memory_type="knowledge",
    content="Python的GIL限制了多线程性能",
    importance=7
)

# 搜索记忆
result = await tool.execute(
    operation="search",
    query="Python GIL"
)
```

#### subagent - 子代理


## 工具注册

### 方式1: 代码注册

```python
from autoagent.tools.tool_registry import ToolRegistry

def my_custom_tool(param1: str, param2: int) -> dict:
    """自定义工具"""
    return {"result": f"{param1} - {param2}"}

registry = ToolRegistry.get_instance()
registry.register_tool(
    tool_name="my_tool",
    tool_func=my_custom_tool,
    schema={
        "name": "my_tool",
        "description": "我的自定义工具",
        "category": "custom",
        "parameters": {
            "param1": {"type": "string", "required": True},
            "param2": {"type": "integer", "required": True}
        }
    }
)
```

### 方式2: 装饰器注册

```python
from autoagent.tools.base_tool import BaseTool, tool_registry

@tool_registry.register(
    name="my_decorated_tool",
    description="使用装饰器注册的工具",
    category="custom"
)
class MyDecoratedTool(BaseTool):
    name = "my_decorated_tool"

    async def execute(self, param1: str, **kwargs):
        return {"result": param1}
```

## 工具执行

### 通过ToolExecutor执行

```python
from autoagent.tools.tool_executor import ToolExecutor
from autoagent.tools.tool_registry import ToolRegistry

registry = ToolRegistry.get_instance()
executor = ToolExecutor(registry)

# 同步执行
result = executor.execute("web_search", {"query": "Python"})

# 异步执行
result = await executor.execute_async("web_search", {"query": "Python"})
```

### 批量执行

```python
# 并行执行多个工具
results = await executor.execute_batch([
    ("web_search", {"query": "Python"}),
    ("weather", {"city": "Beijing"}),
    ("calculator", {"expression": "2+2"})
])
```

## 内置工具加载

工具在系统启动时自动加载:

```python
# autoagent/tools/tools_loader.py

class ToolsLoader:
    def load_builtin_tools(self):
        # 加载网页工具
        self._load_module("autoagent.tools.web_tools")

        # 加载系统工具
        self._load_module("autoagent.tools.system_tools")

        # 加载AI工具
        self._load_module("autoagent.tools.ai_tools")

        # 加载规划工具
        self._load_module("autoagent.tools.planning_tools")

        # 加载委托工具
        self._load_module("autoagent.tools.delegation_tools")
```
