## 模块职责

### 1. Gateway Layer (网关层)

负责统一接入不同消息平台，将各异构协议转换为统一格式。

```
gateway/
├── cli/           # 命令行界面
├── telegram/     # Telegram Bot
├── discord/       # Discord Bot
├── slack/         # Slack Bot
└── whatsapp/      # WhatsApp Bot
```

#### 统一消息格式

```python
class UnifiedMessage:
    platform: str          # 来源平台
    user_id: str           # 用户标识
    content: str           # 消息内容
    message_type: str       # text/image/file
    metadata: dict         # 平台特定元数据
    timestamp: datetime    # 时间戳
```

### 2. Core Layer (核心层)

Agent的核心处理逻辑所在。

#### 组件

| 组件 | 职责 |
|------|------|
| `MessageHandler` | 解析用户意图，提取实体 |
| `ResponseGenerator` | 生成AI响应 |
| `ContextBuilder` | 构建完整上下文 |
| `UserManager` | 用户建模与管理 |

#### 消息处理流程

```
用户消息 → 意图识别 → 实体提取 → 上下文构建 → 技能匹配 → LLM响应 → 工具执行 → 响应生成
```

## 数据流

### 消息处理流程

```
1. 用户通过任意平台发送消息
2. Gateway适配器接收并转换为统一格式
3. MessageHandler解析意图和实体
4. ContextBuilder构建完整上下文
   - 加载对话历史
   - 检索相关记忆
   - 匹配相关技能
   - 获取用户模型
5. SkillManager查找相关技能
6. ResponseGenerator生成响应
   - 选择合适模型
   - 构建Prompt
   - 调用LLM API
7. ToolExecutor执行需要的工具
8. 组装最终响应
9. 通过原平台返回给用户
10. MemoryManager自动保存重要上下文
```

### 技能进化流程

```
1. 用户完成一个复杂任务
2. SkillManager记录任务解决过程
3. Task完成数达到阈值（15次）
4. EvolutionManager开始评估
   - 分析成功率
   - 识别可复用模式
   - 检测优化空间
5. 如检测到可创建技能
   - SkillCreator生成技能
   - 保存到SkillStore
   - 导出为SKILL.md
6. 更新技能统计
```

## 设计模式

### 1. 单例模式

确保全局唯一实例:

```python
class ToolRegistry:
    _instance = None
    _lock = RLock()

    def __new__(cls):
        if cls._instance is None:
            with cls._lock:
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
        return cls._instance
```

### 2. 工厂模式

工具和技能的动态创建:

```python
class ToolFactory:
    @staticmethod
    def create_tool(tool_type: str) -> BaseTool:
        tools = {
            "web_search": WebSearchTool,
            "calculator": CalculatorTool,
        }
        return tools[tool_type]()
```

### 3. 观察者模式

事件驱动的任务调度:

```python
def _setup_event_listeners(self):
    self._scheduler.add_listener(
        on_job_executed,
        EVENT_JOB_EXECUTED
    )
```

### 4. 策略模式

模型路由选择:

```python
class ModelStrategy(ABC):
    @abstractmethod
    def select_model(self, context: dict) -> str:
        pass
```

### 5. 模板方法模式

消息处理流程:

```python
class MessageProcessor:
    def process(self, message):
        parsed = self.parse(message)
        validated = self.validate(parsed)
        return self.execute(validated)
```

## 安全性

### 工具执行安全

1. **白名单命令**: 终端工具仅允许特定命令
2. **沙箱隔离**: 代码执行在Docker容器中
3. **参数验证**: 所有工具参数经过验证
4. **权限控制**: 敏感操作需确认

### 数据安全

1. **密钥隔离**: API密钥独立存储
2. **会话隔离**: 用户数据分离
3. **传输加密**: HTTPS/WSS传输

## 可扩展性

### 添加新工具

1. 继承 `BaseTool`
2. 实现 `execute` 方法
3. 在 `ToolRegistry` 注册

### 添加新平台

1. 创建 Gateway 适配器
2. 实现消息转换
3. 注册到 Gateway

### 添加新模型

1. 实现 Provider 接口
2. 在 Router 注册
