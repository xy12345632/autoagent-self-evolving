## 添加新工具

### 步骤1: 创建工具类

```python
# autoagent/tools/my_tools/my_calculator.py

from ..base_tool import BaseTool

class CalculatorTool(BaseTool):
    name = "calculator"
    description = "执行数学计算"
    category = "utility"

    async def execute(self, expression: str, **kwargs):
        """执行数学表达式"""
        try:
            # 安全评估（仅允许基本运算）
            allowed_chars = set("0123456789+-*/.() ")
            if not all(c in allowed_chars for c in expression):
                return {"error": "表达式包含非法字符"}

            result = eval(expression)
            return {"result": result, "expression": expression}
        except Exception as e:
            return {"error": str(e)}
```

### 步骤3: 实现消息处理器

```python
# autoagent/gateway/wecom/handlers.py

class MessageHandler:
    def __init__(self, agent_core):
        self.agent_core = agent_core

    async def process(self, message: dict):
        """处理消息并生成响应"""

        # 解析消息
        user_id = message.get("FromUserName")
        content = message.get("Content")

        # 转换为统一格式
        unified_message = {
            "platform": "wecom",
            "user_id": user_id,
            "content": content,
            "message_type": "text"
        }

        # 调用Agent处理
        response = await self.agent_core.process_message_async(
            content,
            context={"user_id": user_id}
        )

        # 发送响应
        await self._send_response(user_id, response)
```

## 代码规范

### 命名规范

- 类名: `PascalCase` (如 `SkillManager`)
- 函数/方法: `snake_case` (如 `add_knowledge`)
- 常量: `UPPER_SNAKE_CASE` (如 `MAX_RETRY_COUNT`)
- 私有成员: `_leading_underscore` (如 `_internal_state`)

### 异步规范

```python
# 推荐
async def fetch_data(self, url: str) -> dict:
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as resp:
            return await resp.json()

# 避免
async def bad_example(self, url: str) -> dict:
    resp = requests.get(url)  # 阻塞调用
    return resp.json()
```

### 类型注解

```python
from typing import Optional, List, Dict, Any

def process_message(
    self,
    message: str,
    context: Optional[Dict[str, Any]] = None
) -> Dict[str, Any]:
    pass
```

### 错误处理

```python
# 推荐：具体异常
try:
    result = await client.call_tool("tool_name", params)
except ConnectionError as e:
    logger.error(f"连接失败: {e}")
    return {"error": "服务暂时不可用"}
except ValueError as e:
    logger.warning(f"参数错误: {e}")
    return {"error": str(e)}

# 避免：捕获所有异常
try:
    result = ...
except Exception as e:  # 太宽泛
    pass
```
